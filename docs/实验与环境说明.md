# 实验与环境说明

本仓库包含不同年代、不同作者的独立教学示例，采用按项目准备环境的方式。

## Word、PowerPoint 与 PDF

- `.docx`、`.pptx`：使用 Microsoft Office、WPS 或兼容软件打开。
- `.doc`、`.ppt`：属于旧版 Office 格式，建议保留原件，在需要编辑时另存新版格式。
- `.pdf`：作为阅读参考资料使用。
- `.rar`：从 [Releases 下载目录](大文件下载.md)取得原压缩包后，用支持 RAR 的工具解压。

## Python 与 Jupyter

1. 下载完整的示例目录；保留代码和数据、图片之间的相对位置。
2. 先查看项目内的 `README.md`、`requirements.txt` 或“用前说明”。
3. 为每个项目建立独立环境，按原项目要求选择 Python 版本和依赖。不要把所有课程依赖一次性安装到同一环境。
4. Notebook 可用 Jupyter 或支持 `.ipynb` 的编辑器打开；运行前检查输入文件路径。

```bash
python -m venv .venv
```

依赖有明确的 `requirements.txt` 时，在该项目目录安装：

```bash
python -m pip install -r requirements.txt
```
