数据库表结构概览

regions (地区表)

  • region_id INT PRIMARY KEY
  • region_name VARCHAR(25)

countries (国家表)

  • country_id CHAR(2) PRIMARY KEY
  • country_name VARCHAR(40)
  • region_id INT (FK)

locations (地点表)

  • location_id INT PRIMARY KEY
  • street_address VARCHAR(40)
  • postal_code VARCHAR(12)
  • city VARCHAR(30)
  • state_province VARCHAR(25)
  • country_id CHAR(2) (FK)

jobs (职位表)

  • job_id INT PRIMARY KEY
  • job_title VARCHAR(35)
  • min_salary DECIMAL(8,2)
  • max_salary DECIMAL(8,2)

departments (部门表)

  • department_id INT PRIMARY KEY
  • department_name VARCHAR(30)
  • location_id INT (FK)

employees (员工表)

  • employee_id INT PRIMARY KEY
  • first_name VARCHAR(20)
  • last_name VARCHAR(25)
  • email VARCHAR(100)
  • phone_number VARCHAR(20)
  • hire_date DATE
  • job_id INT (FK)
  • salary DECIMAL(8,2)
  • manager_id INT (FK)
  • department_id INT (FK)

dependents (家属表)

  • dependent_id INT PRIMARY KEY
  • first_name VARCHAR(50)
  • last_name VARCHAR(50)
  • relationship VARCHAR(25)
  • employee_id INT (FK)

查询员工信息

1
SELECT 查询所有员工的名字(first_name)和姓氏(last_name)，按姓氏升序排列。 
SELECT first_name, last_name 
FROM employees 
ORDER BY last_name ASC;

解析

此查询从employees表中选择first_name和last_name列，并使用ORDER BY子句按last_name升序排列结果。

部门员工查询

2
SELECT 查询在部门ID为5的部门中工作的所有员工。 
SELECT * 
FROM employees 
WHERE department_id = 5;

解析

使用WHERE子句过滤department_id等于5的记录，返回该部门的所有员工信息。

国家员工查询

3
SELECT 查询所有在'United States of America'工作的员工。 
SELECT e.* 
FROM employees e
JOIN departments d ON e.department_id = d.department_id
JOIN locations l ON d.location_id = l.location_id
JOIN countries c ON l.country_id = c.country_id
WHERE c.country_name = 'United States of America';

解析

通过连接employees、departments、locations和countries表，使用WHERE子句过滤country_name为'United States of America'的记录。

部门人数统计

4
SELECT 查询每个部门的员工数量，显示部门名称和员工数。 
SELECT d.department_name, COUNT(e.employee_id) AS employee_count
FROM departments d
LEFT JOIN employees e ON d.department_id = e.department_id
GROUP BY d.department_name;

解析

使用LEFT JOIN确保包括没有员工的部门，GROUP BY按部门分组，COUNT()函数统计每个部门的员工数量。

员工经理关系

5
SELECT 查询员工的姓名及其经理的姓名（使用自连接）。 
SELECT e.first_name AS employee_first, e.last_name AS employee_last,
       m.first_name AS manager_first, m.last_name AS manager_last
FROM employees e
LEFT JOIN employees m ON e.manager_id = m.employee_id;

解析

使用自连接将employees表与自身连接，通过manager_id与employee_id匹配，LEFT JOIN确保没有经理的员工也能显示。

高于平均工资的员工

6
SELECT 查询工资高于其所在部门平均工资的员工。 
SELECT e.first_name, e.last_name, e.salary, e.department_id
FROM employees e
JOIN (
    SELECT department_id, AVG(salary) AS avg_salary
    FROM employees
    GROUP BY department_id
) d ON e.department_id = d.department_id
WHERE e.salary > d.avg_salary;

解析

子查询计算每个部门的平均工资，然后连接主查询比较每个员工的工资与其部门平均工资。

非经理员工查询

7
SELECT 查询没有下属的员工（即不是经理的员工）。 
SELECT *
FROM employees
WHERE employee_id NOT IN (
    SELECT DISTINCT manager_id
    FROM employees
    WHERE manager_id IS NOT NULL
);

解析

子查询获取所有经理ID，主查询选择不在经理列表中的员工。

国家地点统计

8
SELECT 查询每个国家有多少个地点（location）。 
SELECT c.country_name, COUNT(l.location_id) AS location_count
FROM countries c
LEFT JOIN locations l ON c.country_id = l.country_id
GROUP BY c.country_name;

解析

使用LEFT JOIN连接countries和locations表，按国家分组统计地点数量。

职位薪资统计

10
SELECT 查询每个工作职位（job）的最高工资、最低工资和平均工资。 
SELECT j.job_title, 
       MAX(e.salary) AS max_salary,
       MIN(e.salary) AS min_salary,
       AVG(e.salary) AS avg_salary
FROM employees e
JOIN jobs j ON e.job_id = j.job_id
GROUP BY j.job_title;

解析

连接employees和jobs表，按职位分组，使用聚合函数计算薪资统计值。

11

解析

14
SELECT 查询所有员工的姓名以及他们所在部门的名称和地点所在的城市。 
SELECT e.first_name, e.last_name,

解析

通过连接employees、departments和locations表，获取员工姓名、部门名称和工作城市。

薪资范围查询

16
SELECT 查询工资在8000到12000之间的员工，按工资降序排列。 
SELECT first_name, last_name, salary
FROM employees
WHERE salary BETWEEN 8000 AND 12000

管理员工统计

17
SELECT 查询每个经理手下的员工数量（经理也是员工）。 
SELECT m.first_name, m.last_name, 
       COUNT(e.employee_id) AS employees_count
FROM employees m
JOIN employees e ON m.employee_id = e.manager_id
GROUP BY m.first_name, m.last_name;

解析

使用自连接统计每个经理管理的员工数量，按经理姓名分组。

薪资等级分类

18
SELECT 查询所有员工的姓名、工资、以及工资等级（小于5000为'低'，5000-10000为'中'，大于10000为'高'）。 
SELECT first_name, last_name, salary,
       CASE 
           WHEN salary < 5000 THEN '低'
           WHEN salary BETWEEN 5000 AND 10000 THEN '中'
           ELSE '高'
       END AS salary_level
FROM employees;

解析

使用CASE表达式根据工资范围分类为不同等级。

地区国家统计

19
SELECT 查询每个地区(region)的国家数量，按国家数量降序排列。 
SELECT r.region_name, COUNT(c.country_id) AS country_count
FROM regions r
LEFT JOIN countries c ON r.region_id = c.region_id
GROUP BY r.region_name
ORDER BY country_count DESC;

解析

连接regions和countries表，按地区分组统计国家数量，并按结果降序排列。

员工家属统计

20
SELECT 查询所有有家属的员工，显示员工姓名和家属数量。 
SELECT e.first_name, e.last_name, 
       COUNT(d.dependent_id) AS dependents_count
FROM employees e
JOIN dependents d ON e.employee_id = d.employee_id
GROUP BY e.first_name, e.last_name
HAVING COUNT(d.dependent_id) > 0;

解析

连接employees和dependents表，按员工分组统计家属数量，HAVING子句过滤有家属的员工。
