# 职业教育 AI 与数字技术教学资源库

面向职业院校教师与学习者，汇集 **2025 春至 2026 秋**的教案、课件、课程标准、授课计划、实验代码、数据集与技能训练资料。

**维护者：李国栋 · 深圳市携创高级技工学校**

相关资源已用于 **70 名学生、3 位教师**的教学。仓库按“学期 → 课程 → 周次 → 资源类型”整理，专题参考资料和完整代码项目单独归档。

本批共整理 **1,525 条资源记录、9 门课程、4 个学期**，另提供 **41 个 Releases 大文件附件**。重复来源保留记录，实际文件按内容合并。

## 使用方式

1. **备课与授课**：先打开课程页，查看课程标准和授课计划，再按周次下载 Word 教案及 PowerPoint 课件。
2. **实验与练习**：下载完整示例目录，阅读其原始 `README.md`、`requirements.txt` 或“用前说明”，再准备数据和依赖。
3. **按需下载**：单个文档可在 GitHub 文件页选择下载；大文件请使用[下载目录](docs/大文件下载.md)中的 Releases 链接。
4. **获取完整仓库**：使用 Git 克隆，或在仓库的 **Code → Download ZIP** 下载。Releases 附件需另外下载。

```bash
git clone https://github.com/zhaoaimer233-hash/Vocational-AI-teaching-resource-library.git
```

不同课程横跨多个教学年度，示例依赖版本并不统一；尚未对全部历史实验逐一执行验证。请参阅[实验与环境说明](docs/实验与环境说明.md)，结合原始说明为各项目单独创建环境。

## 整理与来源

本次整理来源于 2025 年上半年、2025 年下半年、2026 年春、2026 年秋四批教学资料。保留原始文档内容与文件名，通过目录分类、内容校验和索引改善检索体验。

课表、选课单、导师记录、含人员联系方式的内部材料与学生作业汇总未纳入公开仓库；临时文件、缓存、空的损坏文档及已有展开目录的重复打包文件不作为教学资源收录。原仓库根目录的文件已迁入对应课程，见[迁移对照](docs/原仓库文件迁移对照.md)。

第三方资料保留原作者、原说明与已有许可证。公开分享不代表统一采用某一种开源许可证；使用范围以各资料的原授权为准，详见[来源与使用说明](docs/来源与使用说明.md)。
